## 재현 범위와 데이터 기준

이 영상은 외부 모델 API 장애에 대비한 **시나리오 재현물**이며, 편집하지 않은 실시간 서버 녹화가 아닙니다. 렌더링 중에는 외부 API 연결을 차단했습니다.

- **화면**: 실제 프로젝트 프론트 컴포넌트와 스타일을 사용했습니다.
- **Luna**: 저장된 Bistelligence 시트 이미지와 영역 좌표를 사용했습니다.
- **일반 챗봇**: 저장된 Veltrix Systems RAG 실행의 답변과 원본 셀 근거를 사용했습니다. 차트는 연결된 BI 스냅샷을 표시합니다.
- **첨부 비교**: 저장 BI의 원천 지표를 사용해 구성한 예시입니다. 새로운 LLM 응답이 아니며, 영상의 답변과 자막에도 표시했습니다.
- **진행 상태**: 적재·검색·BI 생성의 상태 전환은 시연용으로 재현했습니다. 표시되는 기존 실행의 시간·토큰·비용을 새 작업의 실측 성능으로 해석하지 않습니다.
- **단위**: 시연 재무자료는 USD millions 기준입니다. 실제 기업의 투자 판단 자료가 아닌 프로젝트용 데이터입니다.

성능·정확도 검증은 이 영상이 아니라 [프로젝트 평가 기준](../../PROJECT_SUMMARY.md#평가-결과를-읽는-방법)과 [보존된 실행 기록](../../evaluation/README.md)을 참조합니다.

## 발표에서 사용하기

MP4를 발표 기기에 미리 내려받으면 **API 키와 인터넷 없이 재생**할 수 있습니다. 자막이 영상에 포함되어 있으므로 SRT를 따로 불러올 필요가 없습니다. SRT는 자막 수정이나 다른 편집 도구에서 재사용할 때 사용합니다.

전체 영상과 기능별 GIF 원본을 혼동하지 않도록 MP4·SRT·이 안내 문서는 `docs/assets/demo/`에서 함께 관리합니다.

## README 영상 갱신

GitHub 내장 플레이어에는 저장소의 Raw 다운로드 주소가 아니라 **GitHub에 첨부한 영상 주소**를 사용합니다. 영상을 교체할 때는 10MB 미만의 H.264 재생본을 GitHub 편집 화면에 첨부하고, 생성된 `https://github.com/user-attachments/assets/…` 주소를 루트 README·시연 자료 목차·이 문서에 함께 갱신합니다. 주소는 다른 텍스트나 링크 문법으로 감싸지 않고 독립된 문단에 둡니다.
